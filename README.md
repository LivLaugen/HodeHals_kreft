# Strukturerte dokumenter for hode- og halskreft  
Her ligger det filer som er laget i prosjektet "Strukturert journal for kreft" (SJK)  for hode og halskreft 

---
I mappen **Dokumentasjons** ligger:  
- Dokumenter med skjermbilder fra løsningen  
- `.adoc`-filer med dataelementene, deres bruk og kodesett  
---
I mappen **native** og zip-pakker ligger:  
- `.json`-filer (openEHR native)  
- `.zip`-pakker med både `.json`-filer og alle arketyper brukt i templatet  

Zip-filene kan lastes inn i Arketypedesigneren (AD) for å se templatet der:  
👉 [Arketypedesigneren](https://tools.openehr.org/designer/#/)

---
I mappen  **Eksportskjema** ligger alle filene som er laget til nå for å eksportere data til NORPREG  
> ⚠️ Dette kan endre seg - det er første utkast og ikke gjennomgått tilstreklig iterasjoner.
---
I mappen **local** ligger alle templatfiler og arketypefiler, og som gjør at man kan man koble repoet direkte til AD.
