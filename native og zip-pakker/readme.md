Nativ JSON-fil (Generisk JSON = .t.json)
En nativ JSON-fil er et generelt dataformat som brukes for å lagre og utveksle strukturert data. 
Formål: Den kan representere nesten hvilken som helst type datahierarki. Den brukes ofte som et lettvektig format for API-kommunikasjon eller datalagring.
Struktur: Strukturen er fullstendig fleksibel og defineres av den som lager filen. Det er ingen innebygde regler utover JSON-syntaksen selv.
Standardisering: Ingen spesiell standardisering utover JSON-spesifikasjonen. Det er opp til utvikleren å tolke innholdet.
Data vs. Mal: En generisk JSON-fil er vanligvis en instans av data, ikke en mal for hvordan data skal se ut.
